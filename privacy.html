Privacy Policy

Effective October 29, 2026

Plato is a private assistant used only by the owner of Aristotle Industries. This policy explains how Plato handles data from Google accounts it is connected to.

Who uses Plato

Plato has a single user: the owner of Aristotle Industries. It only connects to Gmail accounts belonging to that owner, and only after the owner signs in and grants access.

What data Plato accesses

With the owner's permission, Plato reads, searches, drafts, and sends email in the connected Gmail accounts. It uses this to summarize the inbox, flag important messages (such as order notifications and messages from key business contacts), and send or draft replies on the owner's behalf.

How data is stored

Access tokens and the records Plato keeps about important messages are stored on the owner's own computer. Plato does not run a public server or database and does not create user accounts.

How data is processed

To read and write email for the owner, message content is processed by an AI model provider (Anthropic) solely to perform the assistant's functions for the owner.

Sharing

Plato does not sell, rent, or share Google user data with anyone, does not use it for advertising, and does not use it to train AI models. Data is only used to provide the assistant's features to the owner.

Plato's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Plato's access at any time from Google Account → Security → Third-party access, and delete the locally stored tokens.
